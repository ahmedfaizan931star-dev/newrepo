# Markdown quick reference for OFFSCRIPT

Paste this syntax into the article body or choose OPEN .MD.

- `# Heading` — large section heading
- `## Subheading` — secondary heading
- `**bold**` — bold text
- `*italic*` — italic text
- `~~removed~~` — strikethrough
- `` `code` `` — inline code
- `> quote` — blockquote
- `- item` — bulleted list
- `1. item` — numbered list
- `---` — horizontal divider
- `[label](https://example.com)` — external link
- `![alt text](./images/cover-culture.svg)` — local bundled cover image

Only the site's bundled SVG cover paths and embedded base64 images are displayed as Markdown images, keeping the article editor offline-first. External web links open only when the reader chooses them.
